# Python Learning Project

A small starter project for learning Python, Git, and GitHub through clear examples and incremental changes.

## Project structure

- `hello.py` — starter program that prints a greeting.
- `README.md` — project overview and run instructions.
- `.gitignore` — excludes Python bytecode and local virtual environments.

## Requirements

Install Python 3 and make sure `python` is available in your terminal.

## Run

```powershell
python hello.py
```
